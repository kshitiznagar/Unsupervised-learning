# Unsupervised Learning

A collection of Jupyter notebooks exploring core unsupervised machine learning algorithms — clustering, dimensionality reduction, and anomaly detection — along with a small applied project.

## 📂 Contents

| Notebook | Topic |
|---|---|
| `Kmeans.ipynb` | K-Means clustering |
| `Hierarchial_clustering.ipynb` | Hierarchical (agglomerative) clustering |
| `DB_scan.ipynb` | Density-based clustering with DBSCAN |
| `PCA_practise.ipynb` | Principal Component Analysis (dimensionality reduction) |
| `Anomalies_detection.ipynb` | Anomaly / outlier detection |
| `Minor_project/Smart_cart_clustering_system.ipynb` | Mini project: customer segmentation using clustering on cart/purchase data |

## 📊 Datasets

- `thyroid.csv` — used for anomaly detection experiments
- `Minor_project/customers_data.csv` — used in the Smart Cart Clustering System project

## 🎯 About

This repository documents my hands-on practice with unsupervised learning techniques — algorithms that find structure and patterns in data without labeled outcomes. Each notebook focuses on a specific algorithm, working through the theory and implementation using Python.

**Topics covered:**
- Clustering (K-Means, Hierarchical, DBSCAN)
- Dimensionality reduction (PCA)
- Anomaly detection
- An applied mini project combining these concepts for customer segmentation

## 🛠️ Tech Stack

- Python
- Jupyter Notebook
- pandas, NumPy
- scikit-learn
- matplotlib / seaborn (for visualization)
